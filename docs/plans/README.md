# 执行计划入口

- 状态：开发准备规划中

当前具体路线见[从发现到开发路线图](discovery-to-development.md)。

首个待评审执行计划见[P0 垂直切片执行计划](p0-vertical-slice.md)。

更细的任务级执行计划将在产品与技术 Spec 接受后建立，至少包括：

- 按用户价值切分的里程碑和垂直切片。
- 每个任务引用的 Spec 条款、输入、输出和完成定义。
- 资产制作与软件开发两条依赖关系。
- POC、质量样片、MVP、商业化阶段的退出条件。
- 测试矩阵、渲染基准、视觉基线和发布检查。
- Creator/Admin 页面清单、组件状态矩阵、响应式线框和 UI 截图基线。
- 风险、负责人、预算、GPU、模型和外部服务等依赖。

在计划冻结前，只允许进行可丢弃的技术 POC，不开始大规模页面或后端实现。
