## 资源与验收边界

- 允许使用既有配置的 GPT、公开参考检索及本地软件。付费视频 API 回退关闭。
- 初始预算为两次关键镜头尝试。执行中第一次因配色冲突取消，第二次在资源争用下整段 VAE 解码显著变慢；明确取消并核对终态后，追加一次分块解码验证。不增加付费调用，不自动无限重试；已有试片可复用。
- 自动测试检查真实状态、可播放、时长、尺寸、非空画面、声音非静音、下载一致性及故障恢复；模型调用记录需可追溯。
- 人工确认主体与动作、成片质感单列，不以自动测试通过或输出为1080p就宣布80分。
