# 2026-09-05 大模型平台定位

- 状态：已记录
- 参与方：项目方、Codex

## 项目方澄清

- “张雪 800X”是一款车，应按用户确认的车型名称处理。
- 平台通过大模型进行文案整理、搜索、素材生成和组装处理。
- 真正执行流程由大模型辅助，项目交付的是平台与工具能力，而不是只制作两条固定视频。

## 形成的架构结论

- 大模型承担意图解析、搜索规划、资料整理、脚本、Storyboard、工具选择和结果评估。
- 媒体生成、Blender、配音、合成和质检以有 Schema 的工具提供。
- 用户确认事实、搜索资料和模型创意分层保存，搜索结果不能覆盖用户明确事实。
- 用户确认后的 Storyboard 编译成不可变任务，后台执行器负责重试与状态恢复。
- 两条内容示例是平台 POC 测试用例，不是平台硬编码模板。
