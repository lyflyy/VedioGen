## 真实失败与重做

首次任务在 KSampler 报 `hostbuf_file_reader_read failed`，上游约 72.80 秒，平台轮询约 74 秒。模型缓冲区读取栈来自 comfy_aimdo；没有成片，平台记录 failed、无 finalArtifactId。

重新计算 Wan diffusion 完整 SHA-256，仍为 `456f901338bd9eadbded3828b819109a9b68e8a525ca5cf8d0049a69fcfeca1e`，未发现该文件损坏。通过 GitHub CLI 检索 [ComfyUI #14281](https://github.com/Comfy-Org/ComfyUI/issues/14281) 和 [#15492](https://github.com/Comfy-Org/ComfyUI/issues/15492)，其他环境存在相同报错；其中重启/更新/重下模型的用户反馈不构成本机根因证据。未随意升级固定的 ComfyUI 或重新下载权重。

在确认队列 running=0、pending=0 后调用本地 `/free` 释放模型与内存缓存，自动 E2E 已结束。通过页面「重做镜头 1」手动创建 attempt=2，同一平台 run 内保留首次失败记录。新的 ComfyUI ID `e6299517-f43d-4bc1-8165-948b721a5d07`，seed `83283552793934`，约 125 秒完成，生成并合成成功。

本次同时改变了缓存状态、测试进程负载和随机种子，不能认定已修复 hostbuf 根因；只证明失败后能显式重做并成功。未自动循环重试，未更改原必需镜头要求。
