# 纯文字素材准备实现记录

## 对齐最新要求

用户只有文字，且希望尽量本地生成，减少付费视频供应商依赖。本轮先实现文字到参考图片准备，不再要求用户先制作模型或上传照片。

## 已完成

- 修正新项目自动 confirmed 车型占位；不把项目标题当作车型。
- 增加 GPT 结构化主体提取，保留必需镜头顺序，复用现有网关配置。
- 接 ddgs 免 Key 图片检索，后台任务持久化、状态查询和刷新恢复。
- 项目资料页展示参考图片、来源、匹配状态；用户确认后真实下载、校验并加入素材，可供现有分镜使用。
- 补名称匹配、跨项目、文本改变、重复导入及外网访问边界测试。

接口细节见 [文字到参考素材契约](../specs/text-reference-preparation.md)。

## 实际联网证据

1. 以 `CFMOTO 800MT motorcycle` 运行 ddgs，返回 RideApart / Motor1 等图片候选；其中也有不同版本与不可靠转载结果，不能直接选择首图。
2. 实际使用新增下载函数获取 `https://cdn.motor1.com/images/mgl/BjVnR/s1/2021-cfmoto-800mt---main.jpg`，195207 字节，JPEG 文件头；SHA256 为 `7ab5632f2d47f1e5be8172b1bf6a0f62328f274b2c784090b251377cec5b7d7b`。只证明文件可获取，未代替用户确认具体版本。
3. “张雪 800X”查询出现无关内容，不能把搜索有返回当作车型已找到，也不替换成凯越 800X。
4. 本地试用环境创建素材检索验证项目 `f2cd0391-5133-4d17-a388-e4646e34eabb`，直接指定检索文字 `CFMOTO 800MT`，未调用 GPT。实际返回候选并在浏览器显示。
5. 初次真实页面发现 800MT-X 被连字符绕过过滤，已统一型号内连字符处理，并新增对应回归。重新发起检索任务 `5bd772a1-a560-416a-96fb-82c40d36c744`，返回 4 个候选，已排除 800MT-X；Explore 等具体版本仍待用户确认。
6. 真实浏览器复查发现搜索引擎缩略图全部加载失败，补上失败后尝试候选原图的回退。修复后 4 张原图均成功加载；两种地址都失败时禁用采用按钮，并通过隔离浏览器测试覆盖。桌面与手机截图位于 `.data/internal-mvp/reference-live-desktop.png` 和 `.data/internal-mvp/reference-live-mobile.png`；390px 手机视口无横向溢出。

试用地址：`http://127.0.0.1:3001/projects/f2cd0391-5133-4d17-a388-e4646e34eabb/intake`。使用 `.data/internal-mvp/`，不修改原 3000/8000 环境。联网试验没有替用户点击“确认主体并采用”。

## 验证边界

- API 集成覆盖模拟 GPT/检索/下载响应到真实本地文件与 FFmpeg 成片的链路。
- Playwright 全套 6 项通过，其中一项候选界面测试使用 UI fixture，不应描述为所有环节均为真实外部服务。
- 后端最终回归 45 项通过，存在 2 项依赖弃用警告。Vitest 3 项、lint、生产构建通过；缩略图回退修复后另外重跑参考素材 Playwright 2 项、lint 与生产构建，均通过。
