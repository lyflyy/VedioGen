# 2026-09-05 生成平台边界讨论

- 状态：已记录
- 参与方：项目方、Codex

## 项目方决定

平台主打通过 AI 与用户交互，从用户素材和文字中生成脚本、生成素材并组装社交媒体视频。项目方决定首期不考虑素材合法性、法律条款和相关风险，也不建设对应产品功能。

## 文档调整

- 从首期产品流程移除素材授权审核、品牌法务审批和法律风险判断。
- 资产信息只保留生成复现、质量判断和系统排障所需字段。
- 将“必须预先具备精品 3D 资产”的单一路线替换为混合生成与组装路线。
- 保留 Blender 作为摩托车高质量镜头的可选执行器，而不是平台核心依赖。

## 工程边界

开源代码、模型和外部 API 的使用条件仍属于技术选型事实，因为它们会决定组件能否部署、是否需要付费以及服务是否可用；这部分只在内部研究和依赖决策中记录，不进入终端用户创作流程。

真实车型的准确度是质量问题。用户只有文字时，生成内容可能出现车型和年款细节偏差；系统通过 Reference Pack、共享参考图、生成参数和用户确认降低偏差，但当前不承诺工程级还原。
