## 真实 HTTP 429

通过真实浏览器进入既有项目策略页，仅执行一次实际创意建议请求，未连续重试。

- 项目：`ab7e2c1a-da94-4519-9e32-6cd3eb05c6d5`。
- 平台：GetTokens GPT，域名 `www.gettokens.cc`。
- 配置模型：`gpt-5.4-mini`。这是请求的物理模型配置，不是中转站内部账号池的实际实现证明。
- HTTP：429。
- 上游 `message`：`All available accounts are currently rate-limited. Please retry later.`
- 上游 `type`：`rate_limit_error`；响应未提供独立 `code` 字段。
- 上游请求 ID：`a50c53e4-9fc6-42d8-a150-43f9e170e2f2`。
- 本地处理：凭据冷却 60 秒，无自动重试。

解释：中转站报告其可用账号均处于限流状态；不能把该信息解释为用户 Key 没有余额。需要中转站恢复可用上游账号或解除限制。

真实详情已在策略页面和项目日志渲染。证据目录 `.data/internal-mvp/project-management/` 保留真实请求的 `real-model-response.png`；按项目 ID 子目录保存复核的 `result.json`、`real-logs-desktop.png`、`real-logs-mobile.png`。后续复核只读取日志，不重新调用模型。仅保存脱敏响应，没有记录 Key。

历史通用 HTTP 错误没有原文可恢复；页面明确标注未保存上游说明。通过日志可以看出调用失败，而不是一直调度中的假进度。
