## 实现范围与依据

依据 [GitHub 版本及源码对照](../research/2026-09-11-video-workflow-practices.md)，保留 GPT 网关、持久任务、ComfyUI/Wan、Blender、FFmpeg 分层。采用分批参考观察、中间结果缓存、逐镜头制作策略、关键试片确认、声音统一合成，而非重写为另一套框架。

- 候选图每批最多四张，覆盖全部候选 ID，观察按素材摘要/模型/路由缓存；完整结果供镜头匹配使用。
- 区分平台推荐与用户固定选择；兼容制作方式切换保留图片，不要求重新上传。
- 计划失效明确阻止旧检查复用；一键生成先做关键试片，未采用不冒充整片就绪。
- 参考图在推理前准备画幅，透明产品图不复制成模糊车辆背景。
- 增加本地电子配乐、声音计划、脚本 Markdown 导出和项目复用入口。
- 后台可配置整段/分块解码，旧任务快照保持原参数。分块只改善资源可执行性，不保证画质。
- 素材匹配失败保留已成功生成的脚本；429 沿用原冷却机制，不盲目重试或切换 Key。
