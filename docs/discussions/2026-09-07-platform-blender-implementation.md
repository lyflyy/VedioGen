# Blender 平台执行与真实工程验证

日期：2026-09-07。前轮新增国际站参考检索，本轮补齐 Blender 执行器，而不是继续扩展照片对照。用户尚未回复具体车型/版本确认；准确车型资产和正式样片验收仍未完成。

## 交付增量

- 管理页可保存独立 Blender 开关、绝对路径和超时，并执行不渲染的版本检查。
- 项目支持 GLB 上传与内嵌资源结构校验，分镜显式选择 `orbit-360` 模板。
- 现有后台队列实际启动 Blender，记录 PID/启动时间/帧目录和进度；支持单镜头试片、取消、恢复、逐镜头重做、采用与合成。
- Blender 脚本移至 API 服务包，旧 CLI 入口转发到同一份实现，避免两套场景脚本漂移。
- 增加 psutil 7.2.2 用于进程身份检查，不自写 Windows 进程枚举。Blender 官方 CLI 与 Python API 的采用依据沿用 [本地路线](../plans/2026-09-07-local-first-media.md)和 [原环绕 POC](../specs/local-blender-orbit-poc.md)。
- GPT 可见执行上下文中新增 Blender 的启用状态和能力限制，不向 GPT 发送可执行文件路径。

完整契约见 [Blender 执行规格](../specs/local-blender-execution.md)。默认配置不启用；本次通过真实管理页面启用了 8001 工程环境的 Blender，ComfyUI 与 Piper 配置保留，没有改动 3000/8000 环境。

## 真实流程发现的问题

### 新建页初始化前输入

浏览器在页面刚返回、React 尚未初始化时填入文字，文本框显示内容，但字符计数仍为 0，“获取创意建议”保持禁用。第一次脚本等提交响应超时，第二次通过提交按钮断言和截图定位；当时没有创建项目、没有调用 GPT。

新建页现在通过 `useSyncExternalStore` 区分服务端与已初始化客户端状态，初始化前禁用输入、文件选择和提交。新增 E2E 故意阻塞客户端 JavaScript，确认控件禁用，再放行脚本并验证输入计数与按钮启用。没有用固定 sleep 掩盖问题。

### GPT 分镜最小数量错误

旧 `STORYBOARD_WIRE_SCHEMA` 强制 5 至 8 个镜头，而平台执行器支持 1 至 12 个。实际只要求一个校准镜头，却得到五个重复镜头。已将 wire schema 对齐 1 至 12，并增加单镜头 schema 回归。

失败分镜 `302211f6-058b-495a-ba7f-c1087ecd1dec` 保留，未静默删减。通过正常 storyboard-runs 接口重新生成，得到一个 3 秒镜头，当前分镜为 `1231d8a5-fb00-4563-bff9-b0ce6233975d`。

### 验证脚本自身恢复

- 脚本在策略自动生成未结束时再次导航到相同策略页，造成两次真实创意建议调用；已移除这次多余导航。调用记录不能按一次汇报。
- 创意建议端点目前没有跨页面刷新期间的服务端请求去重，因此用户在请求中刷新仍有重复调用风险，后续应单独补齐。此次脚本修复不代表平台已经解决该并发风险。
  - 后续进展：已补齐单进程请求合并与成功结果复用，见[创意建议去重记录](2026-09-07-advisor-request-deduplication.md)；不改变此处当时发生两次真实调用的事实。
- 下载验证最初用了不存在的 `/delivery` 阶段，正确阶段是 `/final`。从已完成任务恢复下载，没有重做渲染。
- 采用报告文件重放会复用已有项目、分镜、试片和整片任务；完成后清除报告中的当前 failure，但旧故障截图仍保留。

### 最终显示复核

- 补查最后一处模型素材显示调整：选择 Blender 来源和已有 GLB 后，桌面 1440 x 1000、手机 390 x 844 均显示“GLB 已选择”，不再误报“未选择素材”。截图为同一证据目录的 `glb-selected-desktop.png` 与 `glb-selected-mobile.png`。
- 此次浏览器复核拦截所有非 GET API 请求，仅改变页面临时选择，随后刷新恢复；没有保存分镜、调用 GPT、启动渲染或改变已采用试片。
- 最后这处调整后重新执行 TypeScript 检查与 `git diff --check`，均通过；全量 API / E2E 数字仍为上一次完整测试结果，并非本次重跑。
- 输入边界保持不变：用户只有文字描述也应能开始，平台负责素材检索与准备；准确资产暂缺时应解释缺口并提供候选确认，不能把用户上传照片或 GLB 设为默认前置条件，也不能用校准几何冒充车型样片。

## 余项

准确车型 GLB、张雪具体车型身份、春风正式版本、驾驶/沙漠/涉水/航拍镜头和完整两支样片 80 分人工验收均未完成。新增的环绕执行链路只消除了“准备好模型仍无法在平台渲染”的缺口，没有消除模型准备与画质缺口。下一步应先确认车型并准备匹配几何，同时修复真实创意建议请求的重复提交风险，避免将 GPU 或 GPT 用量花在重复工程样片上。
