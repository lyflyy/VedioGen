# 2026-09-07 官网参考素材接入平台

状态：草案（真实工程流程已执行，正式车型版本与样片待确认）

## 本轮变化

上一轮官网目录是独立工具，本轮将同一解析逻辑移入 `manufacturer_catalog.py`，供平台和研究脚本复用。项目资料页新增素材来源选择，官网参考沿用现有后台检索、候选展示、用户确认、入库和后续分镜绑定流程。

用户依然只需提供文字，不需要自行找网址或下载图片。当前官方来源覆盖春风，未提供所有品牌的通用官网爬虫。原网络图片搜索保持默认并继续可用。

800MT-ES 与笼统 800MT 分开：页面提示相关版本候选，后端要求显式确认版本；未确认不导入，确认后的资产与项目事实保留精确型号。未修改已有正式项目的车型或分镜，也没有将用户未回复解释为同意使用 ES。

详细接口和边界已更新到 [文字参考素材规格](../specs/text-reference-preparation.md)。
