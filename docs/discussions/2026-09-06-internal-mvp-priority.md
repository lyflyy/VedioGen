# 企业内部 MVP 优先级调整

- 日期：2026-09-06
- 状态：用户方向已确认，具体实施与质量评分待检阅

## 用户最新要求

项目是企业内部应用。版本控制、非法内容校验等完整流程可以暂缓，近期首先完成 MVP，并做出 80 分的视频；其他能力在长期规划中补齐。

## 调整结果

- 不再把公众平台的完整治理能力作为真实视频之前的阻断门。
- 近期顺序改为：关键镜头真实 POC -> 第一条完整平台成片 -> 第二个样例复验 -> 内部日更改进。
- 版本历史、复杂审批、内容治理、自建完整权限体系、分布式任务与全面模型评测后置。
- 保留 GPT 咨询和生成前轻量确认；允许人工补素材、选片和修正，最终调用、保存和合成仍通过平台完成。
- 保留必要文件/参数检查、真实任务状态、服务端 Key 和试验费用边界，不把这些扩大成新的治理工程。
- 80 分建议用人工加权评分、关键画面最低分和少量不可接受缺陷定义，不等同任意车型影视级全自动建模。

主执行依据改为[企业内部 MVP 计划](../plans/2026-09-06-internal-mvp-reset.md)。旧架构复核仍作为缺陷记录，旧阶段顺序作为历史候选，不静默删除。

本轮没有开始应用代码整改、真实模型调用或采购；没有把建议评分、视频服务或预算当作用户已确认。
