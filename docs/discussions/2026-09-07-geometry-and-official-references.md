## 前一轮与本轮重点

前一轮完成本地中文旁白的真实执行，属于有效进展。本轮回到画面质量和真正 360 度所需的资产与渲染器，不重新定义两支指定车型样片或 80 分目标。

用户只有文字，平台负责准备参考与工具；未要求用户上传照片、录音或自行制作模型。本轮未调用任何付费图片/视频/语音接口。

## 几何检索证据

2026-09-07 的公开查询：

- Sketchfab 公共 API：`type=models&q=cfmoto 800mt`、`ibex 800`、`ZXMOTO 800X` 均未返回候选。
- `q=cfmoto` 返回 450MT、650MT 配件、ATV 等不同内容，不能据此拥有 800MT。即使其中有 `isDownloadable=true`，也不改变车型不匹配事实。
- GitHub CLI `gh search repos 'cfmoto 800mt'` 返回空数组。GitHub 仓库不是全网几何资产目录，此结果不能推导“没有人制作过模型”。
- DDGS 文本检索超时或无结果；Bing HTTP 返回与请求无关的内容，被弃用，未当成车型结论。
- 本轮仍没有可靠的张雪 800X 几何或图片身份链；没有改成凯越 800X。

查询入口：`https://api.sketchfab.com/v3/search` 与 GitHub CLI。未获取非公开模型、未购买模型或绕过下载限制。

## 官网参考素材有实质进展

读取 `https://www.cfmoto.com/` 的 `__NEXT_DATA__`，通过结构化 JSON 找到当前 `800MT-ES` 的产品路由；进一步读取 [800MT-ES 官网产品页](https://www.cfmoto.com/motorcycles/800mt-es)。

其 `vehicleData` 明确给出车型名、具体图片、尺寸、图片所属章节和画廊。当前数据未发现 `.glb/.gltf/.fbx/.blend` 文件或产品视频，不能把官网图片称为 3D 模型。

新增脚本 `scripts/local-video/inspect-cfmoto-reference.py`：

- 使用标准 HTMLParser 获取 Next JSON，再按 JSON 字段收集图片，不从脚本文本中拼凑资产地址。
- 只处理该车型主体数据及 `cfimages.cfmoto.com` 图片，跳过其他车型推荐、门店和缩略格式。
- 所有条目保留 `model`、上下文、来源页、原图 URL、尺寸和未确认状态。
- 下载复用既有 `fetch_public_image`，生成目录与联系表；不自动导入项目，也不代替用户确认车型或动作。

真实结果：26 个候选，下载了其中尺寸达到筛选条件的前 24 张高清图，未出现下载失败。见 `.data/internal-mvp/cfmoto-official-es/catalog.json` 与 `contact-sheet.jpg`。

已目视检查联系表，包含：静态车身配色、引擎/减震细节、仪表、铺装路面与非铺装路面骑行；部分首屏图含营销文字，不宜直接作为生成首帧。没有足以证明涉水抬头或山林无人机拉远的素材，不能把荒漠背景中的公路骑行说成沙丘扬尘。

编号 12 是仪表；编号 16 是发动机；编号 20/21 是白色/蓝色全车侧面。这些编号属于本轮目录，正式生产还要选定配色与完整镜头对应关系。

已向用户提出一个确认：是否采用 800MT-ES，还是保留此前早期 800MT。发问时没有预设用户已接受 ES，也未把新版本图片混入现有样片。

## Blender 真实执行

已安装并校验 Blender 4.5.13 LTS 便携版本，Windows 可执行文件签名有效、发布 ZIP SHA-256 匹配。详见 [环绕 POC 规格](../specs/local-blender-orbit-poc.md)。

| 测量项 | 实际结果 |
| --- | --- |
| 校准对象 | 三个不同尺寸与颜色的色块，不是摩托车 |
| 首次场景渲染 | 48 帧，脚本记录 20.125 秒，包含首轮着色准备 |
| GLB 导入后渲染 | 48 帧，脚本记录 8.312 秒；不能外推真实车辆性能 |
| 输出 | 540 x 960，24 fps，2.000 秒，48 帧 H.264，无音轨 |
| 完整角度 | 相机 -45 度至 315 度，覆盖 360 度 |
| 画框边界 | 每帧所有校准模型包围盒角点在安全区内 |
| 半圈像素差 | RGB 通道平均绝对差约 18.99 / 13.78 / 14.80，非静帧 |
| 闭环 | 原始 PNG 首尾平均像素差为 0 |
| 浏览器 | Edge 1440 x 900 与 390 x 844，播放推进、画面非空，采样像素平均差约 13.14 |
| MP4 SHA-256 | `f6ba5010bef985098cf64ff072c8acc279479724b8f5590534d57a1db80b40d7` |

实际 GLB 缺失测试退出码为 1，未创建渲染目录，没有默认模型替代。原 ComfyUI 队列在渲染前检查为空；未启动并发视频推理。

证据：`.data/internal-mvp/blender-calibration-orbit/`、`blender-calibration.glb`、`blender-glb-orbit/`。其中 `orbit.json`、`browser-verification.json`、帧图及桌面/手机截图可复查。
