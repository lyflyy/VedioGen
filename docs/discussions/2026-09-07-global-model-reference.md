## 平台新增

现有资料页选择“春风官网”，明确输入 `春风 800MT SPORT` 或 `CFMOTO 800MT EXPLORE` 即可查询相应国际站页面。也接受 SPORT/EXPLORE 前的连字符。沿用既有后台搜索、候选、确认导入，不增加新的工作流。

- 只读产品身份、配色、棚拍画廊、实景画廊的结构化属性。读取标题必须与请求的具体型号匹配。
- 排除导航、推荐、技术热点和非图片文件；仅接收官网固定主机和产品图片路径。保留来源 URL、版本、时间、图片分类。
- 明确型号输入才走国际站适配；泛称 `春风800MT` 仍沿用中文目录的相关版本候选逻辑。此次没有静默把泛称默认分配到 SPORT 或 EXPLORE，也没有自动聚合所有地区目录。
- 候选标记 `official-model-name` 只表示官网页面标题匹配，不表示逐图视觉/年份/配置已核准。`sceneMatchStatus` 始终 unverified，必须看图确认才可导入。
- 界面明确提示国际站同页可能混有不同年份/配置；棚拍照片不等于完整环绕或三维模型。没有自动改写旧素材、车型事实或分镜。

目视检查得到新的限制，不能只按网页标题采用：

- SPORT #14 宽 8256，超过当前平台单素材 8192 像素上限；研究下载成功不等于平台可直接导入。平台仍应明确拒绝，未更改限制或伪造尺寸。
- SPORT/EXPLORE 实景包含山地、土路扬尘和骑行，可用于后续场景参考；不能直接称为沙漠骑行、涉水抬头或山林无人机连续远拉。
