# 策略生成进度与调整入口

## 诉求与决策

用户指出策略页只有“正在形成创意判断”等笼统提示，希望看到具体执行日志和当前步骤，并能进一步调整内容。本轮按真实执行可见性处理，不展示或虚构模型内部思考。

复用已有项目活动接口与 ModelInvocationRow，不新建工作流引擎。新增策略进度组件，使用现有前端布局与 `frontend-design`、`vercel-react-best-practices` 指引；阶段基于应用已有状态，不靠定时器模拟模型工作。

## 实施结果

- 等待、成功、失败展示输入概况、实际模型调用、校验和保存状态。
- 模型等待计时、最近调用详情、HTTP 错误原文和上游请求 ID 可在策略页直接查看。
- 首次无建议、失败、重新生成时均保留原始输入和补充要求入口。
- 防止生成期间的草稿被旧响应清空，防止失败重试重复追加相同反馈。
- 重新打开历史失败策略不自动发起模型调用，需显式重试。

## 验证

- 251 项 API 全量通过，包含新增“能力过滤先于分页”回归；保留 2 条测试依赖弃用警告。
- 7 项相关浏览器验收通过：新增慢响应执行记录、失败刷新与反馈去重，以及既有失败恢复、响应丢失恢复、429 停止等待、后台冷却恢复、完整创作合成下载流程。
- 新增慢响应/失败由隔离浏览器 fixture 控制；成功结果来自隔离 Fake API。没有把这些测试称为真实 GPT 生成。
- TypeScript、ESLint 通过；桌面 1440px 与手机 390px 截图和横向溢出检查通过，新增慢响应界面通过严重可访问性问题检查。
- 已更新 3001 检阅服务，对用户项目 `12747bf9-bf8c-4766-b371-16a41f901dc8` 只读打开策略页，显示已有建议已保存、真实历史日志；本轮没有触发新增模型请求或修改模型配置。
