# 2026-09-05 首批内容示例

- 状态：已记录
- 参与方：项目方、Codex

## 用户提供的内容

示例一要求生成“张雪 800X 最酷视频”，包含车辆聚焦细节、整车 360° 3D 环绕，以及穿皮衣骑手高速驾驶的最后镜头。

示例二以“春风 800MT，真正的越野之王”为主题：先进行 360° 环绕，再展示沙漠扬尘、转速表特写、涉水路面抬头，最后用山林无人机远拉镜头收束。

## 形成的产品结论

- 创作入口以自然语言为主，不要求用户填写完整参数表。
- AI 需要把用户的创意段落扩展为可独立生成和重试的原子镜头。
- 用户指定的镜头和顺序优先保留，AI 负责补充时长、转场、音频和缺失的叙事连接。
- 脚本和 Storyboard 在同一页面集中确认，减少日更创作操作成本。
- 360°、仪表和机械细节适合可控 3D/图片动画；沙漠、涉水、骑手和无人机镜头适合参考图生视频或混合合成。
- 宣传语可以保留，未提供的功率、极速、价格和配置参数不能自动编造。

完整展开结果见[首批摩托车 Storyboard 样例](../examples/2026-09-05-motorcycle-storyboards.md)。
