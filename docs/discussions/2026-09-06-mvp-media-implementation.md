- [x] 本地后台 Run、状态轮询、同项目重复提交复用、停止、局部重做、服务中断后手动继续。

- [ ] 确定视频 Provider、接口/权限、试验预算和车型参考。

由于用户尚未给出视频服务与预算，先交付不消耗新模型额度的上传素材执行能力。没有接一个未经验证的通用“视频端点”，没有自动用图片动画替换 AI 或 Blender 策略。原有 GPT 接入仍保留，本轮未重新消耗真实模型额度测试 GPT。

## 验证结果

- `uv run --project services/api pytest services/api/tests -q`：17 passed，2 条依赖弃用警告。
- `npm run test`：3 passed。
- `npm run lint`：通过。
- Next.js 生产构建使用 `.next-build`，浏览器测试使用 `.next-e2e`，避免产物与常用开发服务共用。
- `npm run test:e2e`：3 passed，覆盖 Admin、Creator 和响应式页面。
- Creator 浏览器实际上传 JPEG、选择镜头素材、生成 12 秒片、刷新恢复、重做第 2 镜头、确认其他片段未重算并下载；文字策略使用隔离 Fixture，不是真实 GPT 创作质量验收。
- 视频在浏览器可解码，采样画面非空且不同时间有像素变化。截图检查桌面 1440px、移动 390px/320px；修复横向素材默认过度裁切和移动端素材编辑不可见的问题。
- API 测试额外覆盖图片/用户视频混合、1080p 输出与非静音背景音频、输入不足/不支持策略、重复请求、取消迟到结果及恢复。
- 测试参考图是仓库的通用摩托车照片，不是已确认的张雪 800X；图片轻微缩放不是 360 度或驾驶。不能把上述测试称作 80 分样片通过。

证据截图在 `apps/web/test-results/creator-flow-creator-uses--f1dc9--compose-retry-and-download-chromium/`，包括 `creator-final.png`、`generation-shots.png`、`storyboard-320.png` 和 `final-390.png`；目录不提交到 Git。

## 本地试用环境

- 新版 Web：`http://127.0.0.1:3001`，API：`http://127.0.0.1:8001`。
- 使用 `.data/internal-mvp/vediogen.db` 和 `.data/internal-mvp/secrets/`。从现有数据库做 SQLite 一致性备份、复制加密配置，没有解密或输出 Key。
