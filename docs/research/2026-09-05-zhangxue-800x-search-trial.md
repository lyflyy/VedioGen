# 张雪 800X 搜索试验

- 状态：已记录
- 日期：2026-09-05
- 目的：验证用户自然语言中的车型如何经过搜索工具形成资料包

## 已确认项目事实

项目方明确确认：“张雪 800X”是一款车，是本项目中的完整车型名称。该信息在后续流程中属于 Project Fact。

## 搜索过程

本轮使用通用网页搜索测试了“张雪 800X 摩托车”“张雪机车 800X”“精确短语张雪800X”和相关站点查询，同时读取 ZXMOTO 张雪机车官网首页。

## 结果

- 通用搜索对中文分词处理较差，多数结果只匹配姓氏“张”，没有返回车型资料。
- 站点限定搜索出现了“凯越 800X”“800X ADV”等结果，属于相似词误匹配，不能作为车型身份结论。
- ZXMOTO 官网首页能确认站点主体为“ZXMOTO 张雪机车”，但本次抓取的首页内容没有直接提供 800X 车型详情。
- 当前检索结果不足以生成可信的具体参数，因此样例脚本没有加入功率、排量、极速或价格。

## 对搜索工具的要求

1. 用户确认事实优先于搜索推断。
2. 中文车型查询需要精确短语、品牌别名、站点限定和图片搜索等多路查询。
3. 搜索结果必须进行实体一致性判断，不能因为型号字符串相同就合并品牌。
4. 搜索摘要只是候选线索；需要读取页面正文后才可进入 Evidence Pack。
5. 找不到资料时应生成视觉化创意脚本，并明确不添加具体性能参数，而不是阻塞整个视频流程。
