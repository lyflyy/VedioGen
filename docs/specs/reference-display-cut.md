# 独立参考图展示版

状态：2026-09-14 已实现。它是原片暂不可执行时的显式替代选项，不是原脚本自动降级，更不是人物驾驶或准确三维影片已完成的声明。

## 用户操作

- 分镜素材任务未完成或存在缺口时，提供“制作参考图展示版”。
- 弹窗列出真实项目图片，最多选择 6 张，按选择顺序各展示 3 秒。可切换中文旁白。
- 确认前明确披露：图片缓慢推近及切换、简短预设展示字幕、本地节奏音乐；不包含原脚本的人物动作、新场景和真实 360 度。
- 确认后创建独立项目副本并进入现有视频生成页，原项目和原脚本不被覆盖。
- 成片沿用现有播放、下载、镜头产物、失败恢复与执行日志。

## 接口与执行

`POST /api/v1/projects/{projectId}/reference-cuts`

请求包含 `storyboardVersionId`、`rowVersion`、`assetIds`、`confirmSimplification`、`narration`。

- 未明确确认返回 422；分镜已变更返回 409。
- 素材必须是本项目已就绪且文件存在的图片，不接收外部任意路径。
- 渲染前验证音频配置和图片基础条件；存在其他视频任务时不创建新副本。
- 相同来源分镜版本、选图顺序和旁白选项复用已创建的展示版及生成任务，防止双击重复创建。
- 复用 `copy_project`、`build_plan`、`create_generation` 与现有 FFmpeg/Piper/本地配乐执行器，不新增视频供应商，也不调用大模型假装生成预设文案。
- 新分镜标记 `executionVariant=reference-display`，清除原镜头的动作、三维、试片和阻断语义；原分镜保留。
- 生成失败不能以静音或假产物替代成功，沿用生成页恢复流程。

## 原片试片调度

“准备并生成视频”发现可执行但待验收的镜头时，即使其他镜头还缺素材，也先启动一个可执行镜头的试片。页面提供试片定位入口；本地模型执行显示实际已用时间。不会自动采用未验收的试片，不移除其他镜头的真实阻断条件。

## 验收边界

API 测试覆盖混合就绪状态、明确确认、版本冲突、非法素材、原项目保留、幂等创建及真实 FFmpeg 合成。浏览器测试覆盖弹窗、移动端、独立项目生成、媒体加载与原稿不变。

参考图展示版只是当前可执行的产品展示路线。原脚本的场景首帧生成、主体连续性、三维资产准备和成片画质仍要单独验收。
