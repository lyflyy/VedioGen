# 文字到参考素材准备增量

- 日期：2026-09-07。
- 状态：后台任务、页面、候选筛选与导入已实现；不等于本地 AI 视频或准确 3D 资产已生成。
- 输入：用户只有文字。主入口位于项目“资料”页，不要求先上传图片。

## 已实现流程

```text
项目文字 -> GPT 提取主体及必需镜头 -> 免 Key 图片搜索
        -> 名称匹配候选 -> 用户查看图片和来源并确认
        -> 下载 JPEG/PNG、校验与保存 -> 当前项目素材
        -> 可绑定现有分镜执行器
```

用户也可在同一页面修正检索主体，直接搜索，避免一次不必要的 GPT 调用。该输入仍是文字，不是要求用户制作文件。首次从描述提取使用 `asset-planner` 能力，未单独绑定时复用已发布的 `creative-advisor` 部署；凭据、错误和调用记录沿用原网关。真实 GPT 调用可能计费，不称为全部免费。

## API

| 接口 | 行为 |
| --- | --- |
| `POST /projects/{id}/asset-discoveries` | 请求 `{subject: null, focus: "", source: "web"}` 从原文提取；指定 subject 则直接检索。可选 focus 为独立镜头关键词，最多 160 字；source 可选 web / manufacturer。202 返回任务 |
| `GET /projects/{id}/asset-discoveries/latest` | 返回 `{run: ...}` 或 `{run: null}`；页面轮询/刷新恢复 |
| `POST /projects/{id}/asset-discoveries/{runId}/candidates/{candidateId}/import` | 需 `{confirmSubject: true}`；官网相关版本候选另需 `confirmVariant: true`。返回已入库 assetId；重复采用复用同一资产 |
| `POST /projects/{id}/assets/{assetId}/crops` | 百分比选区 `{x,y,width,height}`，返回新的项目图片及 previewUrl；原图不变，详见 [参考图构图](reference-image-framing.md) |

全部路径位于 `/api/v1` 下。

任务状态：queued、running、ready（检索完成，不是图片已采用）、empty、needs_clarification、failed、interrupted。持久化在 `asset_discoveries` 表。单进程一个检索任务同时执行，同项目且主体、来源与镜头关键词相同的重复提交返回原任务；条件不同或跨项目忙时 409。服务重启后未完成任务标 interrupted，不自动重复发 GPT 请求。

## 官网素材来源

资料页的素材来源可选择“网络图片”或“品牌官网”。后者是现有异步检索的一种来源，不建立另一套上传或审批流程。

- 当前官网适配支持 CFMOTO/春风与张雪 820RR。未适配品牌或张雪其他型号明确报错，不借用其他车型替代。
- 张雪 820RR 读取固定官网产品页，标题与主体型号均需匹配；使用 HTMLParser 提取产品整车轮播及细节区域，排除导航、推荐车型与图标。整车按官网配色组/视角序号保留；图片不是准确三维模型或连续环绕视频。详见[820RR 实测](../discussions/2026-09-08-zxmoto-model-selection.md)。
- 从当前官网首页的结构化车型目录查找名字，优先精确型号；若只有相关连字符后缀版本，则显式展示为版本候选，不自动认定为用户原车型。
- 读取官网产品页 `__NEXT_DATA__.props.pageProps.vehicleData`，保留具体图片和所属章节，跳过推荐车型、门店、图标和缩略格式；仅接受官方图片域名。
- 明确输入 `春风800MT SPORT` 或 `CFMOTO 800MT EXPLORE` 时读取国际站固定对应页面，从产品组件的 JSON 属性获得配色/棚拍/实景图，排除导航、推荐及技术热点。标题需与明确版本一致；图片年份、配置和动作仍待用户确认。泛称 800MT 不自动切换国际版本。见 [实测与同页混用限制](../discussions/2026-09-07-global-model-reference.md)。
- 每次最多读取三个匹配车型页面、返回 36 个候选。官网页面限定固定 HTTPS 主机及车型路径，不跟随重定向，单页最大 4 MB，不发送模型凭据。
- 官网 `focus` 当前按图片上下文做文本包含匹配；不匹配时会明确说明仅展示车型参考，不承诺语义检索或目标动作已存在。这与网络图片搜索的查询词流程不同。
- 图片标题包含官方版本。`requiresVariantConfirmation=true` 时，页面显示“确认版本并采用”，对话框明确询问是否采用该版本作为项目车型；后端也要求独立的 `confirmVariant` 字段。
- 候选预览不是接受版本。导入才保存确认后的精确 `modelName/subject`，并保留 `requestedSubject`、`referenceSource=manufacturer`、章节上下文及来源。
- 工程测试中程序操作确认只证明流程执行，不能替代项目方对正式样片采用 ES 版本的同意。
- 未自动改写既有分镜和旧素材。用户改变车型后仍要检查是否混用了历史参考，当前没有跨镜头自动视觉身份校验。
- 官网参数文本不自动进入项目事实或旁白；图片与章节结构只用于参考目录。图片不等于完整 3D 资产，静态仪表不等于真实转速变化。

## 逐镜头检索

`focus` 与 `subject` 分开：例如主体「春风800MT」、关键词「仪表」。搜索词由车型及关键词组合，车型过滤仍只针对原主体，不能因为关键词提及其他品牌而替换车型。旧请求省略 focus 时行为保持不变。

页面支持输入关键词，也可从 GPT 已提取的 requiredShots 中选择到输入框，最多取前 160 字，用户可编辑后再提交。选择动作本身不执行搜索；长篇镜头描述不保证是高质量检索词，后续可增强为模型生成的简短检索计划。

请求与结果持久化关键词（结果字段 `searchFocus`），刷新后恢复，导入资产保留 searchFocus 便于回溯。候选 `sceneMatchStatus=unverified`；结果出现并不证明场景、动作、车型版本正确。关键词「沙漠」可能召回沙漠配色车辆，因此不把标题匹配算成镜头匹配。未命中时不自动改成无关键词的泛车型结果冒充完成。

## 主体与匹配

- GPT 输出严格结构 `{subject, requiredShots, clarification}`；subject 必须能在用户原文中找到，不能替换成联想车型。
- 多主体或缺名称时先澄清，不随意选第一款车。
- 搜索使用成熟 `ddgs` 库，最多两条查询，每条最多八条原始结果；仅向搜索端发送主体查询，不发送完整对话或模型 Key。
- 春风与 CFMOTO、张雪与 ZXMOTO 使用显式品牌别名。型号相同但品牌不同不合并；800MTX / 800MT-X 不自动归为 800MT。
- Explore / Sport 等版本仍可能进入候选，需要用户看图确认具体车型、版本和颜色。名称过滤不是视觉识别，也不是参数核实。
- 保留搜索来源 URL。网络图片搜索未读取来源页面正文作为事实证据；官网模式读取结构化图片目录，但不自动采纳车辆参数。不能把搜索标题当成已核验事实。
- 新项目不再把标题直接认作车型，也不因文本含 800MT 就自动标车型 confirmed。发布平台取用户实际选择，不再固定 douyin。
- 旧数据库中的历史占位事实未批量改写，旧项目仍需人工核对；此批次修正新项目入口。

## 导入与使用

- 只有用户点击确认才下载并入库，候选不会自动绑定镜头。
- 图片最大 10 MB，目前接收 JPEG/PNG；WebP 等会明确拒绝，不把无法解码的结果标 ready。
- 下载校验公开 HTTPS 地址、DNS 公网地址、重定向、体积和读取时间；连接固定到已校验 IP，保留原域名的 TLS 校验。请求不携带模型凭据，不使用环境代理。
- ffprobe 验证可解码，保存内容哈希。资产记录 `sourceType=web-reference`、来源、主体及 `subjectConfirmedByUser=true`。
- 用户确认只说明该参考图符合项目需求，不说明图中所有参数属实，更不说明已经获得完整三维几何。
- 项目描述改变后，旧候选不能直接确认采用；跨项目候选不能导入。
- 导入后可在分镜选择该参考图。图生视频、Blender 等是否可执行仍依赖对应执行器；不能自动用图片缩放代替驾驶镜头。

## 外网与测试边界

`VEDIOGEN_ALLOW_EXTERNAL_SEARCH=false` 禁止检索和下载；自动测试环境默认关闭。搜索不要求付费 Key，但依赖公网服务，可能限流、返回乱码、空结果或错误，不能承诺服务可用性。库被锁定为 ddgs 9.16.0。

API 测试替换搜索构造器、GPT 回答和下载传输，并额外禁止 ddgs 底层真实网络。先前测试曾因库延迟加载导致方法级替身未生效，已改为构造器替身并补底层拦截；没有模型付费请求。

浏览器覆盖真实后台的澄清/外网禁用/刷新场景；候选展示与下载失败的浏览器测试使用显式 UI fixture。文字到候选、确认、真实文件入库和 FFmpeg 合成在 API 集成测试中覆盖。上述测试不代表真实 AI 画质通过。
