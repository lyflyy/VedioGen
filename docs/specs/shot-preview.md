# 单镜头试片与采用

- 状态：已实现，真实媒体验证结果另记。
- 范围：轻量 MVP 的逐镜头生产，不建设版本审批树。

## 目的

完整分镜中可能只有一个镜头已有可靠素材。应能先验证该镜头，不要求删除其他分镜或伪造它们的素材，不把局部成功当成整片完成。

## 用户操作

1. 分镜页选择镜头、素材、来源方式、时长和提示词。
2. “保存并试片”先保存整份草稿，仅提交当前镜头；云视频单独确认估算费用，本地不自动切换付费供应商。
3. 当前页查看试片状态、播放和下载，可停止、继续原任务、按原参数重做；刷新恢复该镜头最近一次试片。
4. “采用到当前镜头”保存当前编辑后，检查试片与镜头参数是否一致；一致才绑定生成片段。其他分镜、镜头顺序、完整时长保持不变。
5. 素材齐全、整份分镜确认后，按原来的整片生成流程混合旁白、字幕和音频。采用后的片段按视频素材使用，不再次调用图生视频模型。

## API 与执行

- `POST /generation-runs` 新增可选 `shotId`。省略表示原来的整片任务，仍需 approved；提供表示当前草稿的单镜头试片。
- `scope` 为 `full-video` 或 `shot-preview`，存于现有 request_data 并序列化，不新增任务表或独立 GPU 队列。
- 试片只校验选中镜头的输入和执行能力；旁白和背景音频参数禁止用于试片。现有本地/云端成本、取消和提交恢复保护继续适用。
- 同一活跃任务的重复提交只在 project、storyboard、scope、shotId 一致时复用，不把其他镜头或整片任务误作本次试片。
- 试片输出仍是 `shot-video`。不合成 `final-video`，`finalArtifactId` 始终为空，不更新项目的完成状态或已有整片运行指针。
- `GET /projects/{projectId}/storyboards/{storyboardId}/shots/{shotId}/preview` 返回当前镜头准备度和最近试片，不发起推理。
- `POST /generation-runs/{runId}/adoption` 检查完成状态、当前分镜、镜头参数、实际文件与哈希。只采用最新成功片段，不复制或重新编码文件。
- 参数比较忽略 status、order、startMs；修改画面、源素材、提示词或时长后，旧试片不能静默覆盖。其他镜头的修改不使当前试片失效。
- 采用生成项目内 video asset，保留来源素材 ID、generationRunId 和哈希；当前镜头改为 `user-video`、入点 0、contain，并保存 `previewRunId`。
- 同一片段重复采用幂等；采用不代表车型或画质已通过人工验收。模型输出只是候选片段。

## 测试门

- 不完整草稿可试片，整片保持不可生成。
- 不调用整片合成，不生成最终产物，不替换已有整片指针。
- 活跃任务去重、无效镜头、非法音频参数、失败与重做。
- 单镜头采用、重复采用、过期参数拒绝、已采用片段用于合成时不调用模型。
- 隔离 Playwright：保存、生成、刷新、播放、过期拒绝、采用、下载，桌面/移动端截图与 a11y。
- 真实试片需额外记录实际模型、任务句柄、视频哈希和质量缺口；隔离 fixture 测试不等于真实模型画质验收。
