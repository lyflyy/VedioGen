# 本地中文旁白

状态：草案（已实现并完成真实工程验证，声音表现待人工试听）

## 目的与边界

用户只提供文字时，平台应承担素材准备、脚本和配音生产。当前切片复用已确认分镜的 `voiceover`，用本机 CPU 生成中文旁白，再由 FFmpeg 合成。无需配音 API Key，不接付费 TTS，也不要求用户录音。

这不是“仅凭文字已能生成合格摩托车大片”的承诺。车型身份、真实 360 度、沙漠/涉水动作、配乐与声效依然需要独立解决。

## 采用现有组件

- 引擎：[OHF-Voice/piper1-gpl](https://github.com/OHF-Voice/piper1-gpl)，版本 `1.8.0`，GPL-3.0；2026-09-07 GitHub CLI 查询时 5,479 stars。社区关注度仅作维护信号，不是声音质量证明。
- 接口：官方 Python CLI，独立有界子进程；使用 `--input-file` 读取 UTF-8 旁白，CPU 执行，不传 `--cuda`。不自行实现语音模型。
- 声音：[rhasspy/piper-voices/zh/zh_CN/huayan/medium](https://huggingface.co/rhasspy/piper-voices/tree/main/zh/zh_CN/huayan/medium)，单说话人，22,050 Hz。
- 下载实测走 `hf-mirror.com`，主站当时超时。ONNX 的 SHA-256 与镜像仓库 API 返回的 LFS SHA 一致，不将此表述为额外完成主站签名验证。
- 模型卡将数据集许可标为 `Unknown`，不能因引擎开源就称声音权重已获商用授权。MVP 不新增审核流程，保留来源事实供后续判断。

## 配置与操作

安装可选依赖：`uv sync --project services/api --extra speech`。

在现有 `/admin/video-settings` 配置：

- `narrationEnabled`：默认 `false`。
- `narrationModelPath`：服务器本地 `.onnx` 路径；旁边必须有同名 `.onnx.json`。
- 本地模型访问还受 `VEDIOGEN_ALLOW_LOCAL_MODELS` 控制。

开启保存时验证依赖、文件、配置、中文 espeak 声音类型和采样率。这是配置检查，不是试听或真实推理探测；不自动下载任何模型。

创作端编辑并确认分镜旁白，在生成页勾选“生成本地中文旁白”。`POST /generation-runs` 新增 `narration: boolean = false`。未配置或全部旁白为空时返回 422，不排入假任务。未勾选时保持旧音频行为。

## 执行与时间轴

1. 创建任务时快照声音路径、模型和 JSON 的 SHA-256、采样率及分镜文本。
2. Worker 在视频渲染之前生成旁白，及时发现时长溢出，避免先消耗 GPU 再失败。
3. 每个非空镜头调用一次 Piper，最多 60 秒；生成真实 PCM WAV，验证格式、时长与非静音峰值。
4. 旁白从对应镜头起点播放，余下时间补静音；空旁白镜头保持空白。使用绝对采样边界避免累计舍入误差。
5. 旁白超过镜头时长即失败，显示镜头编号、实际语音秒数及允许秒数。不得截断、默认加速、修改已确认文本或延长画面。用户缩短文案或调整分镜后重新确认、创建任务。
6. 合成时旁白正常音量，素材原声音量 0.2，可选背景音量 0.12，混音后限幅。旧无旁白背景混音仍使用 0.25。
7. 成片保持既有 H.264 / AAC 输出与镜头时长；字幕仍取自 `caption`，不会擅自替换为旁白全文。

运行目录保留 `narration-{index}.txt/.wav`、`narration.wav` 和 `narration.json`，后者记录模型摘要、每段实际语音时长与入点。当前不新增专门的配音资产下载接口。

## 错误与恢复

- 依赖缺失、模型变更、超时、无声音频均明确失败，无静音替代，也无云端兜底。
- 配音或合成失败时不删除成功的视频镜头；恢复同一任务复用成功镜头。CPU 配音当前会重新生成，不承诺位级确定性。
- 管理员停用用于阻止新配音计划；环境本地调用禁令对执行时仍有效。已有任务使用其配置快照，取消不会发布迟到成片。
- 目前配音子进程内部不支持即时取消；取消后可等待当前配音流程收尾，不会发布结果。独立 TTS 队列、持久服务、声音选择、试听、音素对齐与情绪控制列入后续改进。

## 验证要求

隔离测试使用合成测试音验证调度、混音及失败行为，不将测试音宣称为真实 TTS。真实验收单独调用本地 Piper，必须从浏览器生成并下载成片，验证音轨能量、时长、播放及桌面/移动布局，并由人试听中文发音、车型读法和表达质量。

可复用真实检查脚本：`scripts/local-video/verify-local-narration.mjs`。必须显式设置 `NARRATION_TEST_PROJECT`、`NARRATION_TEST_CLIP`、`NARRATION_TEST_VOICE`；该脚本会通过界面修改选定工程项目的分镜，不应指向正式项目。默认目标为 `http://127.0.0.1:3001`。
