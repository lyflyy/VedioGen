# 项目管理与执行日志

日期：2026-09-12。范围为内部 MVP，不引入多租户或正式版本审批。

## 列表与删除

- 项目列表支持服务端搜索、状态筛选、20 项分页，避免只在首次返回的 20 项中搜索。
- 全部不含回收站。待确认包括资料、策略、Brief、分镜及待处理项目，排除实际活动任务；生成中覆盖模型调用、素材准备、脚本准备及视频任务。已完成不含仍有活动任务的项目。
- `GET /projects?status=pending|generating|completed|deleted&query=...&offset=0&pageSize=20` 返回 `items/total/nextCursor`；保留原有精确状态参数。
- `DELETE /projects/{id}` 在明确确认后移入回收站。保存删除前状态，不物理删除素材/成片或关联历史；不会损坏其他项目引用的媒体文件。
- 模型、素材准备、脚本或视频仍在执行时返回 409；停止任务或等待完成后才能删除。使用现有单进程锁协调入口，未承诺多进程调度安全。
- `POST /projects/{id}/restoration` 恢复原状态；回收站项目不能进入普通工作区或发起新生成。永久删除和磁盘垃圾回收暂不提供。

## 错误详情

- OpenAI-compatible 适配器仅提取上游 `error.message/type/code` 与请求 ID；纯文本响应可截断展示，HTML/未知结构不直接回显。
- 对当前 Authorization、Key、完整请求文本、常见凭据字段及 URL 查询参数进行脱敏。只显示允许的错误字段，不回传 headers、完整请求 JSON、加密存储引用或私有文件路径。
- 用户页面的错误提示包含平台、配置模型、HTTP 状态、上游脱敏信息、请求 ID，以及查看项目日志入口。
- 429 仍按明确错误码区分限流与额度暂停；不凭英文 message 猜测余额，不自动无限重试。冷却期本地拒绝明确写“未发送请求”，不虚构一次上游调用。
- 失败调用记录保存配置模型和请求 ID；历史记录未保存的上游原文不能恢复。只有当前部署配置可回查时，页面注明不是历史模型快照。

## 项目日志

- 项目步骤栏和项目卡片提供“执行日志”。`GET /projects/{id}/activity?category=...&offset=0&pageSize=50` 返回项目范围内的记录，不跨项目查询。
- 分类：模型调用、准备步骤、图片与素材、视频制作、输出文件。页面自动刷新并提供手动刷新与分页。
- 复用现有模型调用、准备阶段 events、素材目录、视频执行快照和产物记录，不伪造以前没有记录的事件。
- 展示调用平台/模型、脱敏失败说明、请求 ID、成功调用 Token、耗时；失败调用没有用量信息时不写成零消耗。
- 素材展示文件、来源页、入库类型、复用来源和实际文件链接。官网检索入库不标作 GPT 生图。
- 视频展示执行方式、声音方案、逐镜尝试/状态、参考 ID、原生尺寸、种子、解码模式、输入快照及输出文件。镜头时间沿用任务更新时间时明确标注，不冒充精确逐镜时间线。
- 脚本文档可展开查看当前保存的画面、字幕、旁白与素材绑定；它不是逐次修改的版本历史。
- 不展示模型内部思维链；只呈现实际步骤、可追溯输入/输出摘要和执行结果。

## 当前限制

单项目日志先从既有表聚合再分页，适合当前内部规模；历史量增大后需改成独立活动索引及数据库游标。没有补造历史上游原文、没有物理删除文件，也没有增加新的图片生成供应商。
