# 逐镜头参考图构图

日期：2026-09-07。状态：已实现，属于内部 MVP 增量；不构成影片质量验收。

## 目标与复用

用户只提供文字，平台负责发现、准备参考素材。已采用的候选图进入项目素材库，在分镜中独立选用。本增量把之前终端上的裁剪工作接入分镜页面，避免强迫用户在外部软件准备图片。

前端采用 `react-image-crop` 11.1.2，复用拖动、缩放、触控、键盘和百分比坐标；弹窗复用已安装 Radix Dialog，沿用现有白灰工作台、绿色命令按钮、蓝色焦点与深色图片区，不新增编辑器框架。2026-09-07 使用 GitHub CLI 查询 [dominictobias/react-image-crop](https://github.com/dominictobias/react-image-crop)：4104 Stars、ISC、未归档，最后 push 为 2026-06-21。Stars 是当日关注度，不是质量保证。

后端采用 Pillow 12.3.0（锁文件），复用 EXIF 方向校正和精确像素裁剪。它负责静态参考图；现有 FFmpeg 继续负责镜头与成片合成。本次没有付费图片或视频 API。

## 创作流程

1. 当前分镜选择已有项目图片，点击「调整参考图」。资料页负责搜索和候选采用；本次不复制搜索界面。
2. 默认 9:16，另有 480:832 本地模型、16:9 和 1:1。选区默认居中，支持拖动、边角缩放、位置滑杆与重置；显示实际输出像素。
3. 保存后生成独立 PNG 并应用到当前分镜，fit 设为 contain，原图和其他分镜保持不变；不自动执行「应用到同类镜头」。
4. 此时分镜仍是内存草稿。沿用「保存分镜」或「确认分镜」落库，页面刷新后恢复对应 sourceAssetId；裁剪图自身已持久化，不因未保存分镜而消失。
5. 执行计划将裁剪资产复制到请求快照，本地 ComfyUI、云端图生视频、图片运动沿用同一素材入口，不额外维护一套仅预览生效的裁剪参数。

取消不发请求；保存中禁止重复点击和关闭；加载或保存失败保留明确错误，允许重试。运行中的分镜沿用现有锁定状态。裁剪不自动批准脚本、不自动确认车型。

## 接口

`POST /api/v1/projects/{projectId}/assets/{assetId}/crops`

```json
{"x":30.5,"y":0,"width":38.5,"height":100}
```

- 坐标单位为原图经 EXIF 方向校正后的百分比，与浏览器显示一致。x/y 为左上角，width/height 为选区尺寸。
- 仅接受有限数值；x/y 为 0 至 100，宽高大于 0，选区不能越界；允许 0.000001 的浮点边缘容差，最终像素边界限制在原图内。
- 像素坐标按四条边独立四舍五入，实际输出宽高至少 32 像素；前端尺寸显示采用同一规则，整数舍入允许比例有一个像素误差。
- 素材必须属于该项目、kind=image、status=ready，文件 SHA-256 与快照一致。只处理静态 JPEG/PNG/WebP，最大边 8192、总计不超过 2400 万像素。对多帧图片和解码异常明确拒绝。
- 201 返回新资产：id、sourceAssetId、sourceType=prepared-reference、cropPercent、cropPixels、width、height、sha256、sizeBytes、previewUrl 等；不返回本地 uri。
- 原图的 subject、sourceUrl、sourceImageUrl、subjectConfirmedByUser 仅在原记录存在时继承，不把 false 或未知提升为已确认。
- 未找到项目或本项目素材返回 404；选区/文件不可用返回 422。每次明确保存生成新资产，不覆盖已被运行使用的图片。

## 验证与限制

API 自动测试包含精确颜色和像素、原图不变、来源确认状态不提升、EXIF 方向、越界/非有限值/太小选区、跨项目与文件变更拒绝，以及裁剪素材实际进入 FFmpeg 合成。

浏览器覆盖比例与位置调整、取消、桌面/手机构图、只影响当前镜头、保存后刷新、生成任务 sourceAssetId 与实际下载。隔离浏览器的创意模型是测试桩，不能代表真实模型画质。

裁剪不是补画。整车无法装入目标画幅时，应换参考图、调整镜头或在后续接入场景生成，不能自动切掉车轮、猜测车身或放大冒充环绕。模型原生宽高仍由管理后台配置，竖屏测试需同时使用 480×832；选区比例本身不会自动修改全局配置。

目前没有自动识别骑手/双轮并建议选区，没有分镜语义级自动选图，也没有可靠的真实车型 3D 几何。水印不作自动移除。完整 360 度、沙漠、涉水抬头、无人机远拉与两款车型 80 分验收仍在原 Goal 内。
