# 分镜自动准备与一键生成

## 用户契约

“保存分镜”只保存；“自动准备素材”保存后在后台准备并报告，不开始视频推理；“准备并生成视频”保存、准备、检查、确认、启动本地生成。“生成选项”保留输出尺寸、音频和云端费用确认等定制入口。

界面等待显示真实业务阶段与结果，不伪造推理过程。失败按镜头 ID 和真实顺序定位，不重复拼接错误编号。修改分镜后旧检查结果不能当作新检查结果。

## 接口

- `POST /api/v1/projects/{projectId}/storyboards/{storyboardId}/material-runs?generate=false`：202，持久化准备任务。同项目活动准备任务返回同一 ID。
- `GET /api/v1/projects/{projectId}/material-runs/latest`：刷新后恢复 queued/running 任务。
- 任务字段：`id/status/phase/storyboardVersionId/inputVersion/resultVersion/changes/checks/errorMessage/generationRunId`。
- 阶段：queued → preparing-assets → checking-shots → starting-video（可选）→ completed；缺口为 needs_attention，异常为 failed，服务重启为 interrupted。
- 旧同步 `auto-materials` 接口保留兼容，页面使用后台接口。

## 自动化边界

优先复用有效绑定。图片误绑为“视频素材”且图生视频可用时，安排参考图生成动态镜头；不要求用户先上传视频。缺提示词从现有画面和运镜补齐。不可用文件移除绑定并重新尝试匹配。缺参考图复用现有官网发现与 GPT 匹配能力；找不到时明确保留缺口，不捏造已生成资产。

不会把显式 Blender 几何环绕降级为平面图片运动。没有三维资产时显示该镜头缺口。没有图生视频服务时不会通过伪造视频让检查变绿。云端自动生成不绕过已有费用确认。

准备任务复用单进程 worker 和 DocumentRow。准备开始前以及写回前核对分镜版本；启动生成前再次核对。生产部署仍为单 API worker，跨进程队列与分布式锁不属于本轮。

## 测试与边界

回归覆盖非整数秒、修复错误绑定但保留引用与文案、素材任务重复点击、异步响应、并发分镜修改拒绝覆盖、正确镜头编号以及浏览器保存/准备/生成/下载。

视频任务完成只说明得到真实媒体结果，不自动证明车型一致、环绕几何准确或骑行动作达标。实际抽帧与人工质量验收必须单独记录。

## 画幅整理与片段复用

本地模型为保留参考图添加的灰色补边，不属于真实画面。合成器按已知参考尺寸和模型画幅计算内容区域，移除补边后以完整主体加柔化背景填充竖屏，不把主体直接放大裁掉。`cover` 裁切仍按用户设置执行。

`POST /api/v1/generation-runs/{runId}/recomposition` 为已完成的本地整片复用 `.source.mp4`，创建新合成任务，不提交模型；原任务和成片保留。活动的同源重合成任务复用 ID，其他活动任务拒绝并行；试片、云端任务、缺失源片段不能执行。生成页显示“优化画幅并合成”。新创建的本地视频任务自动使用相同画幅处理。

这是画幅后处理，不是生成新的摄影视角，也不修复车型和动作幻觉。
