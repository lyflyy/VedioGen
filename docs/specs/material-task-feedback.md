# 素材准备任务与反馈

状态：2026-09-13 已实现，沿用现有素材发现、模型网关与持久后台任务，不引入新队列。

## 操作契约

- 全部镜头使用原有“自动准备素材”；当前镜头使用“准备当前镜头素材”。
- 未保存的分镜先保存；无修改时不重复保存。提交期间防重复点击。
- `POST /projects/{projectId}/storyboards/{storyboardId}/material-runs` 立即返回 202。
- 可选查询参数 `shot_id` 指定镜头，不得与 `generate=true` 同用。不存在的镜头返回 404。
- 相同分镜、范围和生成意图的活动任务复用；不同范围的活动任务返回 409，不悄悄复用其他任务。
- 单镜头准备只更新指定镜头；保留其余镜头、时长、顺序及整片声音计划。结果序号沿用原分镜序号。
- 准备期间禁止页面编辑；服务端仍检查并发变更，不能覆盖其他客户端的新编辑。

## 素材与阶段

1. 确认主体：复用 GPT 素材需求提取。
2. 官网检索：使用现有品牌适配；无结果或不可用时复用通用图片检索。
3. 网络检索：明确品牌别名匹配；候选标题命中不等于精确型号已确认。官网存在但需要确认的车型变体不自动采用。
4. 下载入库：复用受限 HTTPS 下载器、Pillow 格式解析与 ffprobe 验证；复用已下载 URL。单图失败记警告，其余候选继续处理。
5. 视觉检查：逐批记录实际检查范围，命中缓存时明确记录复用。
6. 镜头匹配：GPT 根据观察结果分配素材、说明制作限制。
7. 检查完成：区分 `completed`、`needs_attention`、`failed` 和 `interrupted`。

只需要三维资产的镜头不触发无意义的图片搜索。自动下载保留来源且不伪造用户确认。现有图片不能作为真实驾驶、完整 360 度或独立微距照片的替代证明。

## 页面反馈

- 展示任务范围、阶段、耗时、真实时间戳、下载数量、模型检查批次、警告和具体错误。
- 同一分镜的失败记录不依赖 `resultVersion`；刷新后仍可见。旧输入结果标为修改前记录。
- 轮询使用现有 1.5 秒间隔；任务结束后刷新素材库、绑定和缩略图。
- 不渲染模型隐藏推理，不用虚构百分比或定时文案伪装执行进度。
- 碰到模型限流、连接失败或超时停止当前任务，保留已下载图片，不无条件重试。

## 验收

API 覆盖官网到网络回退、部分下载失败、WebP 格式、单镜头隔离、任务范围去重、并发编辑保护和失败记录持久化。浏览器覆盖立即反馈、刷新恢复、失败无结果版本、按钮恢复及桌面/手机布局；现有完整合成回归继续保留。真实验收与缺口见当日讨论记录。
