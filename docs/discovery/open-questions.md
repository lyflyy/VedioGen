# 待确认问题

- 状态：待确认
- 更新日期：2026-09-05

第一轮五项定位问题已经回答。本文件保留确认结果，并继续收敛正式 Spec 所需信息。

## 已确认

1. 首期用户：普通自媒体创作者。
2. 首期商业化：暂不做付费功能。
3. 核心场景：账号日更。
4. 典型输入：创意思路、文字和描述；也允许照片、多角度图片和视频。
5. 工作流：先生成脚本/分镜，用户确认后再继续生成。
6. 内容真实性：默认真实车型；用户有明确意愿时才生成概念车型。
7. 扩展范围：后续支持母婴、育儿等垂直方向。

## A. 首期内容范围

1. 首期准备验证哪些具体品牌、车型、年款和配置？
2. “真实车型”需要达到什么保真度：整体可识别即可，还是灯组、排气、仪表、车架和年款配置也必须准确？
3. 首期是否需要骑手、真人数字人或口播，还是只展示车辆？
4. 一条日更视频的典型主题是车型介绍、知识科普、新闻热点、骑行故事、改装内容还是混合？
5. 系统能否联网检索车型参数和新闻，哪些来源可视为可信来源？

## B. 输出与工作流

6. 首期目标时长、分辨率、帧率、语言和每日每用户生成量分别是多少？
7. 用户必须能编辑哪些内容：脚本、分镜、车型颜色、镜头、字幕、声音、音乐？
8. 当前建议先确认 Creative Brief，再在同一页面确认脚本和分镜；这两个确认点是否接受？
9. 首期只下载成片，还是需要直接发布抖音？
10. 是否接受预览数分钟、最终成片进入队列并在较长时间后完成？

## C. 成本与资源

11. 已有 GPU 型号、数量和预算如何？是否接受按量云 GPU？
12. 免费阶段计划开放给多少测试用户，每人每天允许生成几条？
13. 质量优先时，最终视频可以等待多久？日更是否要求每天固定时间前完成？

## D. 部署与扩展

14. 服务主要部署在中国大陆还是海外？是否允许调用境外模型 API？
15. 用户素材、生成素材和成片需要保存多久？
16. 母婴/育儿方向的首个内容形态是什么：知识口播、图文动画、商品展示、故事还是数字人？
17. 母婴/育儿内容是否涉及医疗、营养和儿童安全建议；生成内容需要达到什么事实准确度？

## 核心文档评审优先顺序

1. 评审 [PRD v0.1](../specs/product-requirements.md) 中的范围、两个确认点和 P0 默认输出。
2. 评审 [体验规格](../specs/experience-spec.md) 中的三栏 Advisor 与 Storyboard 工作台。
3. 评审 [P0 计划](../plans/p0-vertical-slice.md) 的技术基线、Provider 前置条件和 7 至 12 个工作日估算。
4. 确认真实车型保真标准、P0 运行位置、首个模型路径和免费测试规模。

上述内容通过后可以进入 P0 开发，不需要等待所有 MVP 问题一次性解决。
