# ADR-0001：资产优先的 3D 生产路线

- 状态：已废弃，由 ADR-0003 替代
- 日期：2026-09-05

## 背景

目标是自动生成视觉质量高、可用于短视频平台的摩托车内容。真实车辆包含大量独立机械部件、硬表面结构、品牌细节、物理材质和可控运动。现有图生 3D 工具能快速生成带纹理网格，但不能稳定保证拓扑、部件语义、真实尺寸、机械正确性和跨镜头一致性。

## 决策

首期主车型采用经过人工制作或采购、通过技术与视觉质检的 Blender 资产。AI 负责创意、脚本、分镜建议、受控参数、音频与辅助素材；生产 Worker 通过结构化 Shot Manifest 驱动版本化 Blender 场景。

生成式 3D 仅作为实验适配器，用于概念草模、远景道具、场景元素或资产师的起点。它产生的内容经过重拓扑/拆件、材质、绑定和质检后，才可进入正式资产库。

## 理由

- 同一车型能在多个镜头、比例和生成批次中保持一致。
- 可以精确控制车漆、灯光、贴花、轮胎、转向、悬挂和运镜。
- 渲染问题可以定位到资产、场景、镜头模板或参数版本。
- 高成本人工投入可跨多条视频复用，适合模板化商业模式。
- 不把产品质量依赖在当前仍不稳定的自动拓扑与车辆结构生成上。

## 代价

- 上线前必须投入资产制作、采购、清理、绑定和质检。
- 首期可选车型有限，新增真实车型需要明确的资产生产周期和费用。
- 需要建设资产注册表和版本规范。

## 验证条件

P0 必须用一个摩托车资产完成至少三个不同镜头，并验证：重复渲染一致、颜色/贴花可配置、可单镜头重试、预览与最终渲染构图一致、成片达到共同确认的质量样片门槛。

## 可推翻条件

如果生成式 3D POC 能在目标时延和成本内，连续对多款真实摩托车通过拓扑、拆件、材质、绑定和跨镜头一致性检查，可重新评估主车型的生成路线。
