# ADR-0004：视频生成前设置 AI 创意顾问阶段

- 状态：待评审
- 日期：2026-09-05
- 影响范围：产品流程、领域模型、LLM 编排、体验与测试

## 背景

普通自媒体创作者通常只提供主题、零散文案或粗略镜头想法。直接照单生成会把用户未验证的创意假设放大到昂贵的视频生产阶段，也无法体现平台对抖音内容策划的价值。

不同内容类型需要不同判断。摩托车展示依赖车型识别、机械细节和动态视觉；知识型育儿内容更依赖问题共鸣、解释顺序和信息可信度。固定 Prompt 或固定模板无法稳定覆盖这些差异。

市场研究显示，Invideo、HeyGen 和 CapCut 均在渲染前提供关键参数、脚本、场景蓝图、Brainstorm 或对话修改。详情见[市场与复用研究](../research/2026-09-05-market-and-reuse-study.md)。

## 决策

在脚本和 Storyboard 之前加入独立的 `Creative Advisor` 阶段，并设置两个确认点：

1. 用户与 AI 讨论后锁定 `CreativeBriefVersion`。
2. 系统生成脚本和 Storyboard，用户确认后才启动高成本媒体生成。

Creative Advisor 必须：

- 读取账号目标、受众、用户输入、上传素材和已确认 Project Facts。
- 根据需要调用搜索与页面读取工具，建立带来源的 Evidence Pack。
- 先诊断内容机会，再输出 2 至 3 个可比较的 Strategy Proposal。
- 对每个方案解释 Hook、核心承诺、视觉回报、节奏、所需素材、难度、耗时和相对资源消耗。
- 允许用户追问、重写、合并和直接补充约束。
- 不承诺播放量；建议必须区分公开依据、平台方法和创意假设。

用户锁定后形成不可变的 Creative Brief 版本。后续对策略的实质修改创建新版本，并标记已有脚本/Storyboard 是否失效。

## 领域边界

平台核心定义通用对象和确认机制；垂直内容包定义：

- 内容类型、诊断问题和策略评分权重。
- Hook、Proof、Payoff 和 CTA 模板库。
- 领域术语、事实来源优先级和视觉约束。
- 可用镜头类型、素材路由和质量评估规则。

大模型可以建议，但不能静默覆盖用户确认事实。公开资料与账号数据用于决策支持，不作为效果保证。

## 理由

- 在昂贵生成前修正方向，减少整条重做。
- 把平台从“提示词包装器”提升为可解释的创作决策工具。
- 让日更用户更快获得几个清晰方向，而不是面对大量技术参数。
- 通过内容包支持摩托车与后续母婴、育儿等不同方法。
- 方案、选择原因和版本可沉淀为后续效果评估数据。

## 代价

- 比一句话直接成片多一个确认步骤。
- 需要搜索质量、账号记忆、策略结构化输出和版本失效规则。
- 创意质量不能只靠单元测试，需要样例评审和上线后的行为/结果数据。
- 若展示过多理由与选项，会增加普通用户决策负担。

## 降低代价

- 默认只给 3 个方向，每个方向用一句定位、一个 Hook 和一个关键画面先建立差异。
- 用户可以点击“采用推荐方向”快速前进，也可以对话修改。
- 没有足够账号信息时使用垂直内容包默认值，不阻塞用户。
- 搜索或趋势服务不可用时明确标记“基于通用方法”，仍可继续创作。

## 验证条件

使用张雪 800X、春风 800MT 和一个非摩托车样例验证：

1. 每个输入生成 2 至 3 个实质不同且可执行的方向，而非同义改写。
2. 每个方向具有 Hook、受众、承诺、视觉回报、节奏和资源等级。
3. 用户能合并方向并形成新的 Creative Brief 版本。
4. 用户确认的车型和原话不会被搜索结果覆盖。
5. Creative Brief 变更能使依赖的脚本/Storyboard 明确过期。
6. 在没有搜索结果时仍可降级完成流程，并标注依据范围。
